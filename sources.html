Sources- Heatwave Intelligence System

Data Sources and Stake Holders

Forecast Alert and Workflow Steps

  1. Data Collection from remote sensors and satellites
  2. Data Ingestion and Processing through climate forecasting models
  3. Generation of alerts based on severity of HW
  4. Sending alerts the stakeholders and the public regarding HW and SHW

Data Sources

  • AWS Sensors
  • IMD
  • Geostationary Satellite Feeds

Stakeholders and Roles

  • Meteorologists
    • Analyze sensor feeds
    • Verify automated model outputs
  • Disaster Management Officers
    • Issue emergency public alerts
    • Coordinate cooling center resources
  • General Public
    • Receive local advisories
    • Subscribe to mobile alerts

Abbreviations

AWS
Automatic Weather Station. Automated system for real-time data collection
IMD
Indian Meteorological Department: National meteorological service agency.
HW
Heatwave: Period of abnormally hot weather exceeding standard localized thresholds.
SHW
Severe Heatwave: Extreme heat conditions causing severe public health hazard.
